## 座標と計算方法

- **座標**
  - ワールド座標（odom = world。+x が図の右、+y が図の上）。
  - 角度は反時計回りが正。φ は左が正です。
- **カメラ位置**：(xr + 0.08 cosψ, yr + 0.08 sinψ)。
- **真値までの距離と方向**
  - 真値までのベクトル (dx, dy) を、ロボットの向き ψ で前方と左方向に分けます。
    - fwd = dx cosψ + dy sinψ
    - lat = −dx sinψ + dy cosψ
  - 真値の距離 Z は fwd です。カメラの光軸方向の距離で、直線距離ではありません。
  - 真値の方向は φ_true = atan2(lat, fwd)。
- **誤差（推定 − 真値）**
  - ΔZ = z_a − fwd
  - Δφ = phi_deg − φ_true。±180° に折り返します（wrap）。
  - 平面誤差 = √((X − 1.0)² + (Y + 0.9)²)
- **F1 の向き**：`psi_deg` を 0〜360° で表示しています（例：−43.96° → 316.0°）。

## 限界

- 人物 1 人・配置 1 つ・距離約 2.9 m・シミュレーションの結果だけです。一般的な精度を保証するものではありません。
- 件数が少なく（10・3・3）、実行間の差（例：k=6 の ΔZ がやや大きい）が意味のある差かは判断できません。
- 真値はアクターの基準点の設定値で、足元の実際の接地点とずれている可能性があります（未確認）。
- 近い側への偏り（約 0.1〜0.14 m）の原因は未検証です。
- 検出の境界（画角の端、遠距離、遮蔽）、複数人のケース、時刻ずれガード（ODOM_TIME_MISMATCH）の実時間での動作は、まだ試していません。
